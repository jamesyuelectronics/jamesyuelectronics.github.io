3-Phase BLDC Motor Control Board using PID Control

Power schematic

Using easyEDA, the schematics of the circuits were drawn. On the left is the Buck converter(top) and 12V->5V, 5V->3.3V LDOs(bottom).

3 phase inverter schematic

A 3 phase inverter was implemented to drive the BLDC motor, using a Gate Driver(left) and inverter(right, only 1 phase is shown). The gate driver received signals from the MCU and the output was connected to the inverter.
The gate of the MOSFETs at the inverter have an additional resistor and diode in parallel with the resistor already in place to compensate for the slower turn off times, At the MOSFETs, gate-source resistor and capacitor were added for pull-down and self-turn-on prevention. A capacitor was added between the ground and VDD to prevent sudden voltage spikes.

PCB

A PCB was drawn based on the schematic, including power supply, buck converter, LDOs, gate driver+3phase inverter, MCU and UART connection for a live visual feed of the motor's rpm. A four layer structure was used, including two signal, GND and VCC layers. Unused MCU pins were routed out to headers for possible future use.

PID firmware

The motor control was based on PID controls, using PID controls to allow for smooth operation of the motor. The motor speed and PID variable values can be switched using the Live Expressions window in Debug mode, and the firmware for the PID control is shown on the left picture.
